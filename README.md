# MisfortuneTelling

A game developed to express my view of things.

Peer into the crystal ball and receive a personalised misfortune — because the universe has plans for you, and none of them involve comfort.

## How to play

1. Open `index.html` in any modern web browser (no server required).
2. Type your question (or leave it blank for extra mystery).
3. Click **Reveal My Misfortune** and face your fate.
4. Click **Ask Again** to tempt destiny once more.

## Project structure

```
MisfortuneTelling/
├── index.html        # Main game page
├── css/
│   └── style.css     # Dark mystical theme
└── js/
    └── game.js       # Game logic & misfortune pool
```

## Running locally

Just open `index.html` in a browser — there are no build steps or dependencies.

```bash
# macOS / Linux quick-open
open index.html

# Or serve with Python for a proper origin
python3 -m http.server 8080
```
