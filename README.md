# MisFortuneTelling

*A ritual card roguelike about prophecy, pressure, and unfinished readings.*

This is the split-file web project version.

## Files

- `index.html` — page structure
- `style.css` — visual styling
- `script.js` — game logic and data
- `sounds/` — future audio files
- `images/` — future image/icon files

## How to Play Locally

Open `index.html` in a browser.

If future audio/assets are blocked by browser security, run a local server from this folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
